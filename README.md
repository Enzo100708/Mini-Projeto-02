Manipulação de Strings em C

Programa desenvolvido em C para realizar diferentes operações de manipulação de strings, utilizando principalmente vetores, ponteiros, estruturas de repetição e funções.

Funcionalidades

O programa possui funções destinadas às seguintes operações:

Inversão da string: inverte a ordem dos caracteres.

Deslocamento: realiza o deslocamento dos elementos da string e de um vetor associado.

Inversão de caixa: transforma letras minúsculas em maiúsculas e vice-versa.

Rotação: desloca os caracteres da string em determinada quantidade de posições.

Troca de metades: troca a primeira metade da string pela segunda metade.

Cálculo do tamanho: utiliza a função strleng() para determinar o comprimento da string.

Estrutura

As principais funções implementadas são:

strleng() — calcula o tamanho da string.

Inverter() — inverte os caracteres da string.

deslocamento() — realiza operações de deslocamento.

inverterCaixa() — alterna entre letras maiúsculas e minúsculas.

Rotacionar() — realiza a rotação dos caracteres.

trocarMetades() — troca as metades da string.

main() — recebe a string, apresenta o menu de operações e executa a função correspondente.

Entrada

O programa recebe inicialmente uma string de até 10000 caracteres, incluindo espaços. Em seguida, o usuário pode informar códigos numéricos para selecionar as operações disponíveis.

Tecnologias

Linguagem: C

Biblioteca utilizada: stdio.h

Conceitos: strings, vetores, ponteiros, funções, loops e manipulação de caracteres.

Observação

O projeto está em desenvolvimento e algumas funcionalidades ainda precisam de ajustes na implementação, especialmente as operações de deslocamento e rotação. O objetivo é utilizar o projeto para praticar manipulação de strings e estruturas fundamentais da linguagem C.
